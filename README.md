# Calculator

A tiny Python calculator module for basic arithmetic operatons.

## Instalation

No installation needed — just copy `calculator.py` into your project.

## Usage

```python
from calculator import add, subtract, multiply, divide

add(2, 3)       # 5
subtract(5, 2)  # 3
multiply(4, 3)  # 12
divide(10, 2)   # 5.0
```
